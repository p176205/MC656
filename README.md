## Descrição do Projeto

O presente sistema abrange três contextos principais, sendo eles: eleições de Centros Acadêmicos, eleições e deliberações condominiais e assembleias. Seu objetivo principal é oferecer um ambiente centralizado, organizado e transparente, no qual candidatos e membros de uma comunidade possam interagir antes, durante e após um processo eleitoral ou deliberativo.
